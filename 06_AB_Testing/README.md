# A/B Testing Analysis

## Описание проекта

Анализ A/B-теста для оценки эффективности новой версии landing page.

Цель исследования — определить, приводит ли новая страница (`new_page`) к увеличению конверсии пользователей по сравнению со старой страницей (`old_page`).

Анализ выполнен с использованием Python и статистических методов.

---

## Цель исследования

Проверить, существует ли статистически значимое различие между контрольной и тестовой группами и определить, стоит ли внедрять новую версию страницы.

### Основная гипотеза

**H₀:** новая страница не изменяет конверсию пользователей.

**H₁:** новая страница изменяет конверсию пользователей.

Уровень статистической значимости:

`α = 0.05`

---

## Структура эксперимента

### Control

Старая версия страницы:

`control → old_page`

Количество пользователей:

**146,926**

### Treatment

Новая версия страницы:

`treatment → new_page`

Количество пользователей:

**147,552**

Размеры групп близки, что позволяет проводить корректное сравнение.

---

## Основная метрика

В качестве основной метрики использовалась **Conversion Rate**.

Формула:

`Conversion Rate = количество конверсий / количество пользователей`

Поле `converted`:

* `0` — пользователь не совершил конверсию;
* `1` — пользователь совершил конверсию.

---

## Результаты A/B-теста

### Conversion Rate

| Группа    | Conversion Rate |
| --------- | --------------: |
| Control   |      **11.87%** |
| Treatment |      **17.95%** |

Абсолютная разница:

**+6.08 п.п.**

Относительный рост:

**≈ +51.2%**

Таким образом, пользователи тестовой группы конвертируются значительно чаще.

---

## Статистическая значимость

Для проверки различия конверсий был использован **Chi-square test**.

Результат:

* χ² = **2141.11**
* p-value ≈ **0**
* α = **0.05**

Так как:

`p-value < α`

нулевая гипотеза отклоняется.

### Вывод

Разница между контрольной и тестовой группами является **статистически значимой**.

Полученный результат крайне маловероятно объясняется случайными колебаниями при условии отсутствия эффекта.

---

## Z-test для двух пропорций

Дополнительно был выполнен Z-test для сравнения двух конверсий.

Результат:

* Z-statistic = **-46.28**
* p-value ≈ **0**

Результат подтверждает статистически значимое различие между группами.

---

## 95% доверительный интервал

95% доверительный интервал для разницы:

**Treatment − Control**

составил:

**[5.82%; 6.33%]**

Интервал не содержит 0, что дополнительно подтверждает статистическую значимость результата.

Истинный эффект новой страницы оценивается примерно в диапазоне:

**+5.82 — +6.33 процентных пункта.**

## Средний чек

Средний чек рассчитывался только среди пользователей, совершивших покупку.

| Группа    | Average Check |
| --------- | ------------: |
| Control   |         37.50 |
| Treatment |         37.68 |

Разница составляет около **0.18**.

Таким образом, существенного изменения среднего чека не наблюдается.

Основной эффект новой страницы связан преимущественно с **увеличением количества конверсий**, а не с увеличением суммы отдельной покупки.

## Итоговый бизнес-вывод

A/B-тест показал, что новая версия landing page (`new_page`) значительно эффективнее старой версии (`old_page`).

Основные результаты:

* Conversion Rate увеличился с **11.87% до 17.95%**;
* абсолютный прирост составил **6.08 п.п.**;
* относительный рост составил примерно **51.2%**;
* результат статистически значим (`p < 0.05`);
* 95% CI для разницы составляет **[5.82%; 6.33%]**;
* Revenue увеличилась с **654,227.55 до 997,938.36**;
* Revenue per user увеличилась с **4.45 до 6.76**;
* средний чек практически не изменился;
* положительный эффект наблюдается на Desktop, Mobile и Tablet;
* положительный эффект наблюдается во всех проанализированных странах.

### Рекомендация

**Новую версию landing page рекомендуется внедрять**, поскольку она демонстрирует статистически значимый и практически существенный рост конверсии и выручки на пользователя.

Перед полным rollout дополнительно рекомендуется проверить:

* корректность рандомизации пользователей;
* длительность эксперимента;
* сезонность;
* технические ошибки;
* guardrail-метрики;
* стабильность эффекта во времени.
