# ClickHouse

Изучение ClickHouse в рамках подготовки к собеседованию на позицию Data Analyst.

## Что изучено

- Что такое ClickHouse
- OLAP и колоночное хранение
- `MergeTree`
- `ORDER BY`
- `PARTITION BY`
- `SELECT`
- `WHERE`
- `GROUP BY`
- `LIMIT`
- `COUNT`
- `SUM`
- `AVG`
- `MIN` / `MAX`
- `uniq`
- `uniqExact`
- `argMax`
- `WITH`
- CTE
- Оконные функции
- `row_number()`
- `rank()`
- `dense_rank()`
- Накопительная сумма через `sum() OVER`

## Где выполнять SQL

SQL сначала проверяется в **DBeaver** в SQL-редакторе ClickHouse.

После проверки рабочая версия сохраняется в соответствующий `.sql` файл в VS Code.
