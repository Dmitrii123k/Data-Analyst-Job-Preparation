Подготовка к собеседованию Data Analyst

Практический репозиторий для подготовки к работе Data Analyst / BI Analyst.

Здесь собраны учебные материалы, практические задания, аналитические проекты и решения типовых задач, которые используются в работе аналитика и на технических собеседованиях.

Основные направления

* SQL и работа с реляционными базами данных
* Excel
* Power BI
* Tableau
* Python и pandas
* Статистика
* A/B-тестирование
* DWH и ETL
* ClickHouse
* Аналитические бизнес-кейсы
* Подготовка к техническим собеседованиям

Стек

SQL: PostgreSQL, ClickHouse

Python: Python, pandas, NumPy, SciPy

BI: Power BI, Tableau, Metabase, DataLens

Data: SQL, статистика, A/B-тестирование, DWH/ETL

Tools: DBeaver, VS Code, Git, GitHub, Docker
