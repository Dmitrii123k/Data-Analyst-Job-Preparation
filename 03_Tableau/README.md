# 📊 Аналитический дашборд продаж — Tableau

## 📌 Описание проекта

В рамках проекта разработан интерактивный аналитический дашборд в **Tableau** на основе данных интернет-магазина.

Дашборд предназначен для анализа ключевых показателей продаж, динамики выручки, количества заказов и географии продаж.

Проект является частью портфолио **Data Analyst** и демонстрирует навыки работы с BI-инструментами, визуализации данных и формирования аналитических выводов.

---

## 🎯 Цели проекта

Основные задачи проекта:

* проанализировать общую выручку компании;
* оценить динамику выручки во времени;
* проанализировать количество заказов по месяцам;
* определить основные страны по объёму выручки;
* оценить количество проданных товаров;
* рассчитать среднюю стоимость заказа;
* представить результаты анализа в удобном интерактивном дашборде.

---

## 📈 Основные показатели

На дашборде представлены следующие ключевые показатели:

* **Total Revenue** — общая выручка;
* **Orders** — количество заказов;
* **Customers** — количество уникальных клиентов;
* **Quantity** — общее количество проданных единиц товара;
* **Avg Order Value** — средняя стоимость заказа.

---

## 📊 Основные визуализации

### Revenue Trend

График динамики выручки во времени позволяет оценить изменение продаж и определить периоды роста и снижения.

### Orders by Month

График показывает количество заказов по месяцам и позволяет анализировать динамику активности покупателей во времени.

### Revenue by Country

График показывает распределение выручки между странами и позволяет определить основные рынки компании.

Анализ показывает значительную концентрацию выручки в **United Kingdom**, которая формирует основную часть продаж.

Для повышения читаемости страны отсортированы по объёму выручки, а значения отображаются непосредственно на графике.

---

## 🔎 Основные выводы

По результатам анализа можно выделить следующие наблюдения:

1. Основная часть выручки приходится на **United Kingdom**.
2. Выручка между странами распределена неравномерно.
3. Небольшое количество рынков формирует значительную часть общей выручки.
4. Динамика выручки позволяет выявлять периоды роста и снижения продаж.
5. Количество заказов по месяцам позволяет оценивать изменение активности покупателей.
6. Показатель **Avg Order Value** позволяет оценивать среднюю стоимость одного заказа.

## 🖥 Результат

Результатом проекта является интерактивный Tableau-дашборд, который позволяет быстро оценить основные показатели продаж, динамику выручки, количество заказов и географию бизнеса.
